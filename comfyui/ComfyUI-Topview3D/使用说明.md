# Topview 3D Builder · ComfyUI 插件

已包含完整前端、4 个内置人物、姿势素材和本地解码器，无需 Agent、账号、API Key 或单独启动 Node.js。

## 开始使用

插件界面跟随 ComfyUI 设置中的语言，包括节点按钮、工具栏、渲染预览导出按钮及状态提示。
支持简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、俄语、阿拉伯语、土耳其语、印尼语、马来语和越南语。
语言切换不修改场景数据；不支持的语言回退为英语。后端和第三方组件的原始技术报错保留原文。

1. 重启 ComfyUI，并刷新浏览器页面。
2. 双击节点画布，搜索 `Topview 3D Builder`，或在 `Topview` 分类中添加。
3. 点击节点上的 **打开 3D Builder**，进入占窗口宽高 90% 的居中浮窗。
4. 添加人物、道具，调整姿势、相机和时间轴。
5. 点击编辑器内的 **导出**，设置图片或视频、机位、分辨率和帧范围，点击 **导出到 ComfyUI 画布**。图片或视频导出成功后会自动保存场景、更新卡片预览并关闭浮窗，返回画布；导出或保存失败时保留编辑器以便重试。
6. 点击顶部 **保存并退出**，自动保存场景、更新卡片预览并关闭浮窗。保存失败时保留编辑器并显示错误，可以重试。
7. 在 ComfyUI 中保存工作流，场景和关键帧会随节点属性一起保存。

可将 `examples/topview-3d-preview.json` 拖入 ComfyUI，打开双人姿势示例。

## 导出与保存

- Builder 卡片没有输入输出端口，作为场景编辑入口使用。图标、说明文字和预览图均支持直接拖动节点。
- 导出的视频节点按视频比例自动适配高度，调整宽度时同步适配；视频画面可拖动节点，底部播放控件保持可操作。
- 导出图片会新增 `LoadImage` 节点；导出视频会新增 `LoadVideo` 节点，可连接后续工作流。
- 导出文件位于 `ComfyUI/input/topview3d/exports`；“下载”按钮仍支持下载到本机。
- “保存并退出”将相机预览 PNG 和对应场景 JSON 保存至 `ComfyUI/input/topview3d`，同时更新节点属性；它不代替 ComfyUI 的工作流文件保存操作。
- 旧工作流中的场景数据会自动迁移，Builder 原来的输入输出端口及连线会被移除；内部节点 ID 保持不变。
- 预览来自当前拍摄相机和时间轴帧。换电脑或预览缓存被删除后，打开场景并保存退出即可重新生成。
- 不需要人物名称或网格时，可关闭场景显示设置中的角色标签、地面。
- 不包含 Depth、Normal、OpenPose、外部模型导入或后台无人值守渲染。
- 一次打开一个编辑窗口；使用 ComfyUI 已有的 Pillow / aiohttp，无需安装新的 Python 包。

更新后请重启 ComfyUI 并用 Ctrl+F5 刷新浏览器，以加载新的节点定义和界面。

单行工具栏左侧显示场景名称与保存状态，中间保留 Auto 和 **导出**，右侧为 **保存并退出**。图片、视频类型在导出弹窗内选择。加载失败时可点击 **重试** 或 **不保存退出**；不保存退出会恢复打开编辑器之前的 Builder 节点场景状态。
